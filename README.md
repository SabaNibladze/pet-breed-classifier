# Pet Breed Classifier

ეს პროექტი Upgaming-ის Machine Learning Engineer (Computer Vision) დავალებისთვის გავაკეთე. ამოცანა მარტივია: სურათზე კატის ან ძაღლის ჯიშის ამოცნობა. მონაცემად Oxford-IIIT Pet Dataset ავიღე (37 ჯიში, დაახლოებით 7400 სურათი), მოდელებად კი წინასწარ გაწვრთნილი ResNet18 და MobileNetV3-Small, რომლებიც ჩემს მონაცემებზე დავაზუსტე.

## რა გავაკეთე

- სურათები 224x224-ზე დავიყვანე და train/val/test ნაწილებად გავყავი (2944 / 736 / 3669). train-ზე გამოვიყენე მარტივი augmentation (შემთხვევითი ამოჭრა და სარკისებური გადაბრუნება).
- ResNet18-ზე ორი ვარიანტი ვცადე: ჯერ მხოლოდ ბოლო ფენა გავწვრთენი (baseline), მერე მთელი მოდელი (fine-tuning).
- იგივე ამოცანა გავუშვი MobileNetV3-Small-ზე, რომ პატარა მოდელთან შედარება მქონოდა.
- საუკეთესო მოდელი test ნაწილზე შევაფასე და შეცდომები გავაანალიზე.
- ResNet18 გადავიყვანე ONNX ფორმატში და CPU-ზე სისწრაფე შევადარე.
- ბოლოს Gradio-ზე პატარა ვებ-დემო გავაკეთე.

## შედეგები

| მოდელი | val | test | ზომა | CPU, 1 სურათი |
|---|---|---|---|---|
| ResNet18, მხოლოდ ბოლო ფენა | 87.5% | - | - | - |
| ResNet18, fine-tuning | 90.2% | 85.7% | 44.9 MB | 54.6 ms |
| ResNet18, ONNX Runtime | - | იგივე | 44.8 MB | 31.3 ms |
| MobileNetV3-Small | 81.8% | 77.2% | 6.4 MB | 8.8 ms |

ორიოდე შენიშვნა:

- val-ზე 90.2% მქონდა, test-ზე კი 85.7%. val მხოლოდ 736 სურათია და საუკეთესო epoch სწორედ მის მიხედვით ავირჩიე, ამიტომ test-ის რიცხვი უფრო სანდოა.
- ONNX-ზე გადაყვანის შემდეგ პასუხები პრაქტიკულად არ შეცვლილა (მაქსიმალური განსხვავება 6.6e-7), სისწრაფე კი დაახლოებით 1.7-ჯერ გაიზარდა.
- MobileNet-ს 5 epoch არ ეყო, ბოლო epoch-ზეც იზრდებოდა, ამიტომ მასთან შედარება სრულად სამართლიანი არ არის.
- მოდელი ყველაზე ხშირად ერთმანეთში ერევა ძალიან მსგავს ჯიშებს, მაგალითად American Pit Bull
